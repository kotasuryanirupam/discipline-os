# Code of Conduct — Discipline OS

## Our pledge

This project exists to help one person (and anyone who forks it) build discipline.
Participation — issues, discussions, pull requests — should be useful and respectful.

## Expected behavior

- **Be precise.** Vague feedback wastes everyone's time; specifics are kindness.
- **Assume good faith.** Everyone here is learning in public.
- **Stay on topic.** Issues are for the codebase, not for debating someone's lifestyle.
- **Respect the product's philosophy.** This is an opinionated personal tool; "make it
  configurable" is not a bug report. See [CONTRIBUTING.md](CONTRIBUTING.md).

## Unacceptable behavior

- Harassment, insults, or personal attacks
- Trolling, bad-faith arguments, or deliberate disruption
- Publishing others' private information without consent
- Spam, self-promotion unrelated to the project

## Enforcement

Maintainers may edit, lock, or remove comments, and may temporarily or permanently ban
contributors who violate this code. Reports: **kotasuryanirupam@gmail.com** — include
links and context; reports are handled confidentially.

## Scope

Applies within project spaces (repo, issues, PRs, discussions) and when representing the
project publicly.
